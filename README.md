# ⚽ Crea tu equipo de fútbol — Web con pipeline DevSecOps

Aplicación web para construir tu propio equipo de fútbol, con base de datos y, lo más interesante, un **pipeline de Jenkins que automatiza los controles de seguridad** sobre la aplicación. Proyecto en equipo que une desarrollo web y DevSecOps.

## 🎯 Qué demuestra

- Aplicación web con **persistencia en base de datos** (gestión de jugadores y equipos).
- **Integración continua con Jenkins**: automatización del ciclo de build y de las comprobaciones de seguridad.
- Mentalidad **DevSecOps**: la seguridad no es un paso final manual, sino parte automatizada del pipeline ("shift left").
- Trabajo **colaborativo** en equipo con control de versiones.

## 🔒 El ángulo DevSecOps

Lo que diferencia este proyecto de una web de clase corriente es el **pipeline de Jenkins**: cada cambio desencadena de forma automática las comprobaciones de seguridad, de modo que las vulnerabilidades se detectan temprano en el ciclo de desarrollo en lugar de en producción. Es la idea central del desarrollo seguro moderno aplicada a un proyecto real.
